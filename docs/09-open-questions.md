# 09 — Open Questions (decide before Phase 0)

Defaults (⭐) are what the plan currently assumes.

1. **Name** — ⭐ *Woofdoku* · Barkdoku · Pawzzle · other?
2. **Tech stack** — ⭐ React + TS + Vite · Svelte · vanilla TS · Phaser (full game engine)?
3. **Bonus cadence** — ⭐ every 5th level · every 4th · every 6th?
4. **MVP mini-games** — ⭐ Connect the Leashes, Block Drop, Sliding Pup · swap any for Kibble Blocks / Nonogram / Rush Hour?
5. **Can bonus levels be failed?** — ⭐ No (always ≥ small reward, skippable after first try) · Yes (must pass to continue)?
6. **Wrong placement feedback** — ⭐ validate against solution & cost a bone (like Meowdoku) · free placement, checked only at the end?
7. **World gates by stars** — ⭐ soft (none; stars only boost chest) · hard gate?
8. **Timer** — ⭐ shown but never required · hidden · timed challenge mode?
9. **Levels** — ⭐ pre-generated & curated JSON · fully runtime-generated (infinite)?
10. **Art** — ⭐ custom SVG dogs (placeholder emoji until Phase 4) · pixel art · photos?
11. **Hosting** — ⭐ GitHub Pages · Netlify · Vercel · local only?
12. **Language(s)** — ⭐ English only · English + Dutch (i18n from the start)?
